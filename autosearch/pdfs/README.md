# Reference PDFs

The original test_intel research bundled vendor PDFs for the Intel 4004/4040/8080/8086 manuals,
the Z80 user manual and undocumented-opcode reference, and the 8282 datasheet. They are not
redistributable through GitHub due to size (~140 MB total) but are all freely available online:

- Intel MCS-40 (4004) User Manual: archive.org/details/MCS40UM
- Intel MCS-40 (4040) User Manual: archive.org/details/MCS40UM
- Intel MCS-80 (8080) User Manual: archive.org/details/intel-mcs-80-mcs-85-microcomputer-systems-users-manual-1981`n- Intel iAPX 86/88 User Manual: archive.org/details/iAPX_86_88_Users_Manual_198101
- Zilog Z80 User Manual UM008003: zilog.com
- Sean Young 'The Undocumented Z80 Documented' v0.91: z80.info
- Intel 8282/8283 datasheet: datasheetarchive.com

Drop the PDFs in this folder if you want them locally; the .md notes one level up
do not depend on the files being present.
